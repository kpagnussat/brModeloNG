# Segurança

## Versões atendidas

Correções de segurança saem na versão mais recente da
[página de Releases](https://github.com/kpagnussat/brModeloNG/releases/latest).
Versões anteriores não recebem correções; atualize para a mais recente.

## Como relatar uma falha

Use o
[relato privado de vulnerabilidades](https://github.com/kpagnussat/brModeloNG/security/advisories/new)
do GitHub. Não abra uma issue pública para uma falha ainda não corrigida.

Informe a versão (em **Ajuda → Sobre**), o sistema, o pacote usado (Flatpak,
`.deb`, `.rpm`, `.msi`, jar…) e os passos para reproduzir. Se a falha depender
de um arquivo, descreva como ele é montado ou anexe um exemplo inventado, sem
dados de outras pessoas.

O projeto é mantido por uma pessoa, no tempo livre. O relato recebe resposta
pelo próprio aviso do GitHub e, quando confirmado, a correção sai numa nova
versão, com crédito no [CHANGELOG](CHANGELOG.md) se você quiser.

O que o programa faz para se proteger, e onde cada proteção vale, está na seção
[Segurança](README.md#segurança) do README.

## English

Security fixes ship in the latest release only. Please report vulnerabilities
privately through
[GitHub's private vulnerability reporting](https://github.com/kpagnussat/brModeloNG/security/advisories/new),
not in a public issue. Include the version (Help → About), your system, the
package you use and steps to reproduce. The project has a single maintainer;
confirmed reports are fixed in a new release and credited in the CHANGELOG if
you wish.
